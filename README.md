# 🌍 Climate Change Prediction Model | DSKC ML Intern Project

This repository contains the work completed during my **Machine Learning Summer Internship at DSKC** (June–July 2024), where I developed a predictive model for analyzing and forecasting multiple climate-related parameters.

## 📌 Project Overview

Climate change poses significant environmental, social, and economic challenges. This project uses **machine learning** and **deep learning** techniques to forecast **15 critical environmental parameters** such as temperature, sea level, carbon emissions, and more — supporting better policy and planning decisions.

## 🧠 Technologies & Methods

- **Machine Learning Algorithms**:
  - Linear Regression
  - Polynomial Regression
  - Exponential Regression
- **Deep Learning Techniques**:
  - Artificial Neural Networks (ANN)
  - Convolutional Neural Networks (CNN)
- **Libraries & Tools**:
  - Python, Pandas, NumPy, Scikit-learn, Matplotlib, TensorFlow/Keras

## 🚀 Model Results

- Successfully predicted future trends for 15 environmental metrics.
- Models were evaluated using RMSE, MAE, and R² score.
- Deep learning models outperformed traditional regressors in long-term forecasting accuracy.
